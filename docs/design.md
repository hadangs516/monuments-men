# 모뉴먼츠 맨 · 사라진 제단화

## 플레이어와 약속하는 것

플레이어는 1945년 연합군 문화재 전담반의 신임 조사관이다. 헨트에 사는 소녀 리네는 피란을 떠나기 전 아버지와 함께 그리던 제단화의 분수가 아직 거기 있는지 묻는다. 조사관은 아이에게 대답하기 위해 성에 남은 운송표를 찾아 광산에 들어간다. 그림을 찾아내도 사건은 끝나지 않는다. 끝에서는 누가 돌려받을 권리가 있는지 증명하고 편지에 답한다.

## 사료와 창작

헨트 제단화의 노이슈반슈타인 성 경유, 알타우스제 보관, 뮌헨 집결, 1945년 8월 브뤼셀 도착과 벨기에 당국 인계는 미국 국립문서기록관리청 자료를 따른다. 리네와 가족, 주인공, 단서와 조사표, 퍼즐, 현장 그림은 게임을 위한 창작이다. 실제 제단화 사진은 별도로 표시한다. 참고 자료는 게임 안의 작전 기록에서 열 수 있다.

## 검토한 기획

| 방식 | 플레이에서 확인한 문제 | 결정 |
| --- | --- | --- |
| 광산 잠입과 시간제한 | 모바일 회전이나 읽기 속도가 실패를 좌우하고 미술품이 단순 보상이 된다. | 시간제한을 빼고 관찰과 판단에 무게를 둔다. |
| 장소마다 객관식 질문 | 역사 지식이나 무작위 선택으로 넘어갈 수 있고 사건마다 손맛이 같다. | 기록 대조, 그림 복원, 출처 입증의 세 가지 조작으로 바꾼다. |
| 실제 회화 패널 맞추기 | 원화를 임의로 자른다는 잘못된 인상을 준다. | 현장 대조 사진 여섯 조각의 위치를 맞춘다. |
| 작은 물건 찾기 | 작은 화면에서 탭이 빗나가고 시력이 진행 조건이 된다. | 44px 이상 표식과 수첩형 현장 목록을 함께 제공한다. |

## 사건과 난이도

1. **빈 액자가 남은 성**. 포장공의 표시와 화물 기록 두 가지를 모은다. 어느 한 조건만 맞는 오답을 포함한 네 운송표에서 올바른 노선을 찾는다.
2. **소금 아래의 정원**. 현장 기록으로 사진의 위아래와 중심을 추론한다. 3×2 사진판에서 두 칸을 눌러 맞바꾸며, 다 맞춘 뒤 원화와 대조한다. 여섯 칸 순열은 720개이고 시작 배치에서 세 번의 교환으로 완성된다.
3. **돌아갈 주소**. 최초 소장처를 보여 주는 전쟁 전 기록과 현재 인수 권한을 보여 주는 위임 문서를 한 쌍으로 고른다. 현 위치, 이전 운송장은 소유권을 입증하지 못한다. 인계 도시까지 선택해 귀환을 마친다.

각 장에 선택 수집물 하나를 둔다. 수첩에 기록한 선택 수집물이 마지막 답장에 한 문장씩 들어가므로 다시 조사할 이유가 생긴다. 오답은 틀린 조건을 지목하고 재시도하도록 한다. 사진 퍼즐에는 단계별 힌트와 현재 배치 한 쌍을 바로잡는 보조 기능을 둔다.

## 제작 순서와 확인 조건

- 첫 화면과 첫 장을 연결한다. 시작부터 단서 확인, 오답, 정답까지 터치와 키보드로 진행한다.
- 두 번째와 세 번째 장을 연결하고 각 결론이 다음 장소를 여는 이유를 대화에 담는다. 모든 현장과 조사 도중의 사진 배치를 기기에 저장한다.
- 엔딩에서 원화와 답장을 함께 보여 준다. 수첩에서 수집물과 사료를 열고, 지나간 현장을 다시 방문할 수 있게 한다.
- PC·작은 휴대폰·모바일 가로 화면과 두 브라우저 엔진에서 버튼, 사진 비율, 글자 겹침, 새로고침 복구를 확인한다. 캡처를 열어 보고 수정한다.
- 파비콘과 1200×630 공유 카드를 작은 크기에서 비교한다. GitHub Pages의 HTML, 그림, 공유 메타데이터, 실제 공개 플레이 동선을 확인한다.
